# Dossier produit

## 1. Résumé
MajorDome est un assistant familial proactif. Le produit doit réduire la charge mentale en coordonnant agenda, tâches, routines, opportunités et maison, sans obliger l'utilisateur à jongler entre une dizaine d'applications.

## 2. Problème
Aujourd'hui, une famille répartit son quotidien entre :
- calendriers perso et pro ;
- rappels ;
- emails ;
- notes ;
- outils école/santé/banque ;
- assistants vocaux ;
- domotique.

Le coût cognitif vient de la **fragmentation** et du manque d'anticipation.

## 3. Proposition de valeur
MajorDome doit :
- centraliser le contexte ;
- détecter les conflits avant qu'ils arrivent ;
- générer les préparations nécessaires ;
- produire des briefs clairs ;
- aider à écrire, relancer, planifier ;
- faire de la veille utile ;
- piloter la maison quand cela sert l'usage ;
- respecter la frontière entre perso, pro et foyer.

## 4. Personae
### A. Parent organisateur
Veut réduire les oublis et la charge logistique.

### B. Couple bi-actif
Veut gérer les conflits pro/perso, les enfants, les rendez-vous, l'intendance.

### C. Utilisateur power-user Apple/Google/Microsoft
Veut unifier sans perdre le contrôle de ses systèmes existants.

## 5. Jobs to be done
- “Aide-moi à ne rien oublier cette semaine.”
- “Dis-moi si ce rendez-vous entre en conflit avec autre chose.”
- “Prépare-moi le message pour relancer un tiers.”
- “Regarde si une aide ou une opportunité utile est sortie.”
- “Dis-moi ce qu'il faut préparer pour demain.”
- “Pilote la maison en fonction du contexte, pas juste sur commande.”

## 6. Périmètre fonctionnel cible
### 6.1 Noyau
- calendrier unifié ;
- tâches et routines ;
- briefs quotidiens ;
- détection de conflits ;
- actions assistées.

### 6.2 Couche proactive
- saved searches ;
- opportunités ;
- préparation contextuelle ;
- follow-ups automatiques.

### 6.3 Couche maison
- scènes ;
- consommation ;
- ménage/robots ;
- alertes contextuelles.

## 7. Exemples de cas d'usage
### Routine enfant
- jeudi : livres bibliothèque ;
- mercredi soir : préparation ;
- jeudi matin : rappel ciblé.

### Réparation tondeuse
- l'utilisateur dicte la situation ;
- MajorDome prépare le mail ou trouve le numéro ;
- MajorDome propose un follow-up si aucune réponse.

### Opportunité administrative
- une aide est détectée ;
- le système résume ;
- propose le formulaire ;
- crée une tâche si nécessaire.

## 8. Politique d'autonomie
MajorDome doit fonctionner avec cinq niveaux d'action :
1. Info
2. Suggestion
3. Draft
4. Confirmation
5. Auto

La valeur du produit vient moins de l'autonomie maximale que du **bon niveau d'autonomie selon le risque**.

## 9. MVP recommandé
Le MVP doit rester étroit :
- Google + Microsoft + Apple bridge ;
- calendrier unifié ;
- tâches/routines internes ;
- briefing ;
- conflits ;
- agent pour commandes simples ;
- opportunités simples ;
- drafts email/message.

## 10. Ce qu'il ne faut pas mettre dans le MVP
- banque profonde ;
- santé très sensible ;
- domotique riche marque par marque ;
- téléphonie automatique ;
- promesse d'agent autonome complet.

## 11. KPI de succès V1
- taux de connexion des 3 calendriers ;
- nombre de conflits détectés/utiles ;
- taux d'ouverture des briefings ;
- nombre d'actions assistées utilisées ;
- taux d'opportunités jugées pertinentes ;
- réduction perçue de charge mentale.
