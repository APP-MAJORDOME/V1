# Stratégie d'intégration

## Objectif
Éviter le piège du produit qui branche trop de systèmes trop tôt.

## Ordre recommandé
1. Google Calendar
2. Microsoft Graph
3. Apple bridge
4. tâches internes solides
5. emails/drafts
6. veille web / RSS
7. Home Assistant
8. le reste seulement si un vrai signal usage l'impose

## Règle de décision
Une intégration ne rentre que si elle améliore clairement l'un de ces quatre blocs :
- calendrier ;
- tâches ;
- actions ;
- opportunités.
